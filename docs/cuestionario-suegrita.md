# Cuestionario para usted

Estamos construyendo una herramienta para administradoras de propiedad horizontal en Colombia. Sin lo que usted sabe (10 años en este sector), nos vamos a equivocar feo. Este cuestionario es para que nos cuente con sus palabras cómo se hacen las cosas de verdad.

**Reglas sencillas:**

- No hay respuestas malas.
- Si una pregunta no le gusta o no aplica, sáltela.
- Si quiere alargarse, alárguese: cuanto más nos cuente, mejor.
- Puede llenarlo en computador (Word, Google Docs) o imprimirlo y escribir a mano.
- Si una palabra le suena rara o de "computador", táchela y escriba como usted le diría.
