# Amazon Resale Project

Espacio de trabajo para el proyecto de generación de ganancias mediante venta/reventa en Amazon.

## Objetivos

- Investigar cómo funciona el modelo de venta/reventa en Amazon.
- Analizar mercados y nichos rentables.
- Identificar la forma más segura y legal de operar.
- Definir un plan de acción paso a paso.

## Estructura (pendiente de definir)

A medida que avancemos iremos creando subcarpetas para:

- `research/` — investigación de mercado y modelos de negocio.
- `suppliers/` — proveedores y fuentes de productos.
- `products/` — análisis de productos candidatos.
- `legal/` — requisitos legales, fiscales y de cumplimiento.
- `finance/` — costes, márgenes y proyecciones.
